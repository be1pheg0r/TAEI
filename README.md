# TAEI

Базовый каркас Python-проекта. Требуется Python 3.12; окружение и зависимости
управляются через [uv](https://docs.astral.sh/uv/).

## Рабочий процесс

Код разрабатывается на `hermes-vps`: изменения, локальные тесты и проверки,
затем коммит и push в Git. Пользователь самостоятельно забирает изменения
через `git pull` и запускает код на вычислительном сервере. GPU-задачи и
эксперименты по SSH автоматически не запускаются.

## Установка

```bash
uv python install 3.12
uv sync --group dev
```

Основные зависимости (ClearML, Loguru, Rich и python-dotenv) устанавливаются
обычным `uv sync`. `nano-vllm` — отдельная GPU/CUDA-зависимость: она зафиксирована
на конкретном коммите и не устанавливается на CPU-хосте по умолчанию, чтобы не
запускать сборку FlashAttention и загрузку CUDA-стека. Для inference установите
её отдельно на совместимой GPU-машине:

```bash
uv sync --group dev --extra inference
```

Для первого запуска ClearML заполните `.env` по образцу `.env.example` и
настройте учётные данные ClearML в окружении. Импорт модуля логирования сам по
себе не требует входа в ClearML.

## Работа

```bash
uv run pytest
uv run ruff check .
uv run isort --check-only .
uv run ruff format --check .
uv run pre-commit run --all-files
```

Установить Git-хук (уже установлен в локальном репозитории):

```bash
uv run pre-commit install
```

Хук автоматически исправляет Ruff lint-ошибки, сортирует импорты isort и
форматирует файлы Ruff. После автоисправлений повторно добавьте изменённые файлы
в индекс.

## SSH-конфиг (справочно)

Основной рабочий процесс — Git push/pull и самостоятельный запуск пользователем.
SSH-конфиг сохранён для использования вручную при необходимости.

Конфигурация подключения изолирована в этом репозитории: шаблон
`.ssh/config.example`, локальные настройки `.ssh/config`. Глобальный
`~/.ssh/config` не меняется. SSH сам не подхватывает конфиг проекта — передавайте
его через `-F`. Все команды ниже выполняйте из корня TAEI.

Локальный `.ssh/config` уже создан; после клонирования создайте его из шаблона:

```bash
cp .ssh/config.example .ssh/config
chmod 700 .ssh
chmod 600 .ssh/config
```

В `.ssh/config` замените `HostName` и `User`, при необходимости `Port` и
`IdentityFile` (по умолчанию `~/.ssh/id_ed25519`). Ключ не создаётся автоматически.
Локальный конфиг, отпечатки серверов и ключи внутри `.ssh/` исключены из Git;
версионируется только шаблон.

Проверить конфигурацию без подключения и открыть SSH-сессию:

```bash
ssh -G -F .ssh/config taei-remote
ssh -F .ssh/config taei-remote
```

При первом подключении сверяйте отпечаток ключа сервера с доверенным источником.
Он сохраняется в `.ssh/known_hosts` этого репозитория; проверка ключей включена,
проброс SSH-агента отключён.

Код должен отдельно находиться на сервере, например в `~/TAEI` после клонирования.
После установки `uv` на сервере окружение и тесты можно запустить удалённо:

```bash
ssh -F .ssh/config taei-remote \
  'cd ~/TAEI && uv sync --locked --group dev --extra inference && uv run --locked pytest'
```

Команда предполагает совместимое GPU/CUDA-окружение на сервере. Сам SSH не
синхронизирует файлы; адрес сервера, авторизация и удалённое выполнение пока
не проверены.
