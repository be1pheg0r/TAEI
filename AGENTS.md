# Работа над TAEI

- Код разрабатывается в `/root/TAEI` на `hermes-vps`.
- Перед коммитом выполняются локальные тесты и pre-commit с Ruff и isort.
- Подготовленные изменения передаются пользователю через Git commit/push в согласованный remote.
- Пользователь самостоятельно делает pull и запускает код на вычислительном сервере.
- Не запускать GPU-задачи, обучение, inference или эксперименты по SSH без отдельного запроса пользователя.
- Локальные тесты без GPU допустимы; успешные локальные проверки не означают проверку GPU-запуска.
- Не коммитить `.env`, SSH-конфиг, приватные ключи и учётные данные ClearML.
- Если remote не настроен, запросить URL репозитория; не создавать и не публиковать репозиторий произвольно.
