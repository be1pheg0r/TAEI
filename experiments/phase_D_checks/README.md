# Разборы фазы D без GPU

Четыре проверки по уже снятым данным `data/qwen-3-06b-local/phase_{A,C,D}`. Модель
и формулы ядра не менялись. Выводов о модели «от N» здесь нет.

Запуск — из этой папки, на E-ядрах:

```bash
cd experiments/phase_D_checks
for s in rps knees s6_vs_s2 kappa; do
  nice -n 19 taskset -c 12-19 ../../.venv/bin/python $s.py
done
```

Полный вывод — в `out/<скрипт>.md`. Ниже — коротко.

## 1. RPS закрытого цикла — `rps.py`, `out/rps.md`

В отчёте RPS теперь считается как число завершений, реально попавших в окно,
делённое на длину окна (`nano_time/local_report.py`, `_closed_loop_run`). Раньше
вместо числа завершений брались плановые 200. Объёмы на запрос
(`new_per_request`, `out_per_request`) делятся на то же число.

- **Где сдвинулось.** Заметно только у W1, где у всех запросов одинаковые L и
  O, поэтому они завершаются пачками по N: 9 точек из 30 сдвинулись на ±2–8%.
  Ещё одна точка — W4 с кэшем, N = 32: −2,3%. У S5, W2 и W3 сдвиг не больше 0,8%.
- **Проверка по Литтлу** (среднее число в системе / средняя задержка). При
  ≥ 16 завершений на слот медианное расхождение 0,3%, среднее со знаком −0,02%.
  При < 8 завершений на слот граница окна даёт ошибку порядка
  «N / завершений», поэтому там Литтл не годится как проверка.

## 2. Колени KV — `knees.py`, `out/knees.md`

**Как считалось.** B_KV оценивается по пулу запросов: блоки целые, собственные
блоки запроса усреднены по его жизни и взвешены по O, общие блоки — самый
длинный префикс семьи среди работающих запросов (Монте-Карло). Ёмкость меньше
на половину того, что нужно новому запросу при приёме. Факт — средний B в
decode-шагах, когда в очереди кто-то ждёт.

**Результат.**
- **Ошибка падает** с +3…+14% у оценки сетки до −1…+3% везде, кроме W3 с кэшем.
- **Вес по жизни** даёт основной выигрыш у нагрузок со смешанными O: S5, W2, W4.
- **У W3 с кэшем ошибка меняет знак, потому что ошибок две, и они разного
  знака.**
  - Сетка вычитала общие блоки по самому длинному префиксу каждой семьи во всём
    пуле — 95 блоков. Работающие на колене запросы держат в среднем 64.
  - На колене всего ~6 запросов, каждый занимает до четверти KV. Упор
    случается, когда работают длинные запросы (35 блоков против 33 по пулу) и
    ждёт длинный (26,5 блока против 20,5).
  - Новичку не хватает места в 100% таких шагов. Средние по пулу эту выборку
    не видят: остаётся +11%.

## 3. S6 против S2 — `s6_vs_s2.py`, `out/s6_vs_s2.md`

Форма ядра d0 + d1·Σℓ + d2·B подобрана на S2 и S6 вместе. Поправка на фазу —
множитель (1 + δ) у фазы D. Бутстрэп по точкам: повторы одной точки идут
вместе, потому что у S2 все повторы с одним сидом.

- **Значимого сдвига между фазами нет.** На всех попытках δ = −0,2%, 95%
  интервал [−2,9%, +2,9%]. На пересечении областей (105 попыток S6) δ = −2,7%,
  интервал [−5,3%, +0,7%].
- **Расхождение — в области данных, а не в фазе.** Подбор только на S2 занижает
  S6 на 11–14% при B ≤ 32. S6 лежит вне области S2: Σℓ до 45k при малых B.

| B | 1 | 2 | 4 | 8 | 16 | 32 | 64 | 96 |
|---|---|---|---|---|---|---|---|---|
| S2, общий подбор | −2,4% | −7,7% | −5,5% | −1,8% | −1,3% | +3,6% | +2,8% | +1,0% |
| S6, общий подбор | −0,5% | −3,1% | −2,5% | −3,1% | −3,4% | −4,3% | −0,4% | −0,8% |
| S6, подбор только на S2 | −10,8% | −13,2% | −13,5% | −14,4% | −14,2% | −13,1% | −2,8% | −0,4% |

## 4. Цена общего префикса в decode (S7) — `kappa.py`, `out/kappa.md`

Σℓ_eff = U + κ·(Σℓ − U), где U — уникальные токены шага. U считается по
фактическому C из трассы, так что R = 0,999 при ℓ = 1025 учтён. d0, d1, d2
подобраны на попытках фазы D без общих блоков: S6 и контроль S7 R = 0,
медианная ошибка 2,2%. Точки, где повторы дают меньше 10% Σℓ, исключены (B = 4,
4 семьи).

- **κ ≈ 0,5:** 0,505 по всем точкам, 0,519 при совместном подборе d и κ. Decode
  платит примерно за половину повторённых токенов.
- **κ нестабилен.**
  - **По B:** при B = 4 κ ≈ 1, экономии нет. Оценка по форме там даёт 1,45 только
    из-за ошибки формы, а парный контроль R = 0 даёт 1,01. При B = 8–24 κ = 0,40–0,50.
  - **По числу семей:** у 1 семьи κ = 0,54–0,60, у 4 семей — 0,32–0,39.
  - **По ℓ и R** почти не меняется: 0,39–0,50.
  - **Внутри B = 32, ℓ = 1025** парный κ растёт с R от 0,11 до 0,45: экономия не
    пропорциональна числу повторов.
  - **Квартили по точкам** (±0,1–0,3) шире порога шума: ошибка T в 1% сдвигает
    κ на 0,02–0,03.
