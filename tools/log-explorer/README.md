# TAEI · Log Explorer

Веб-инструмент для исследования архивов журналов экспериментов. Приложение изолировано от зависимостей GPU-экспериментов: FastAPI разбирает архивы, React и Apache ECharts показывают результаты.

## Запуск на этом сервере

```sh
cd /root/TAEI/tools/log-explorer
docker compose up -d --build
curl --fail http://127.0.0.1:8091/api/health
```

`compose.yaml` использует существующую внешнюю Docker-сеть `outline-stack_edge`. Публичный HTTPS обслуживает существующий Caddy; блок виртуального хоста находится в `Caddyfile.fragment`. Он добавляется в `/opt/outline/Caddyfile` без изменения остальных виртуальных хостов. После проверки конфигурации требуется reload Caddy. Сам контейнер слушает с хоста только `127.0.0.1:8091`.

Для отдельной установки создайте свою Docker-сеть и замените имя сети в Compose, либо используйте собственный reverse proxy. TLS и DNS обслуживаются reverse proxy, а не приложением.

**Особенность существующего Caddy:** файл конфигурации смонтирован как отдельный read-only bind mount. Редактор с атомарной заменой файла может оставить контейнер на старом inode. Не считайте успешный reload доказательством подключения нового хоста: проверьте публичный `/api/health`. Для применения без остановки соседних сервисов скопируйте актуальную конфигурацию в контейнер и загрузите её явно:

```sh
docker cp /opt/outline/Caddyfile outline-stack-caddy-1:/tmp/taei-Caddyfile
docker exec outline-stack-caddy-1 caddy validate --config /tmp/taei-Caddyfile --adapter caddyfile
docker exec outline-stack-caddy-1 caddy reload --config /tmp/taei-Caddyfile --adapter caddyfile
```

Каноническая конфигурация остаётся в `/opt/outline/Caddyfile`; после пересоздания контейнера bind mount использует актуальный файл. Не публикуйте полную конфигурацию других виртуальных хостов.

## Использование

1. Откройте сервис. Пример — предоставленный пользователем `logs-2.zip`, а не синтетический эксперимент.
2. Загрузите ZIP или RAR своего эксперимента через выбор файла или перетаскивание. Формат определяется по содержимому, а не расширению имени.
3. Используйте разделы обзора, графиков, журнала, всех значений и файлов. Исходные идентификаторы и значения доступны без сокращения в подробностях.
4. Экспортируйте разобранные данные, таблицы и изображения графиков через элементы интерфейса.

Успешное выполнение генерации и принятие датасета QC — разные результаты. Предоставленный пример содержит завершённую генерацию и отклонённый primary dataset. Числа `qc.counts` являются сводкой, а не самими строками трассы. По ним нельзя восстанавливать время генерации, throughput, latency или временные ряды GPU. Недоступные измерения не заменяются нулями или придуманными данными.

Текущий runtime TAEI пишет в `run.log` строки `Starting experiment: ...`, краткое `metrics: key=value, ...` и `Finished experiment: ... · results: <path>`. Компактная строка — только предпросмотр: вложенные и другие невыведенные значения в неё не входят, даже если `+N more` отсутствует. Путь к `results.json` — только текст журнала: сервис не читает файлы с исходного сервера. Положите `results.json` рядом с логами в загружаемый архив, чтобы получить полные метрики и записи запусков; при нескольких файлах `results.json` сервис не объединяет данные с неоднозначным происхождением. Сам runtime `logs.zip` намеренно включает лишь журналы. Архивировать `results.json` и структурированные трассы в `logs.zip` runtime не обещает.

Описание неизвестного поля явно обозначается как общее пояснение, а не утверждение о документированной семантике. Для полноценного анализа трасс загрузите JSON/JSONL/CSV с данными запросов, шагов, событий и телеметрии вместе с журналами.

## API

- `GET /api/health` — состояние процесса.
- `GET /api/example` — разбор встроенного предоставленного примера.
- `POST /api/analyze` — multipart-поле `file`, ZIP- или RAR-архив; возвращает отдельный результат анализа.

Результат содержит `archive`, `summary`, `metrics`, `runs`, `records`, `fields`, `tables`. Архивы пользователей не публикуются по URL и не сохраняются как общая текущая сессия. Загрузка временно помещается в дисковый spool `/var/spool/log-explorer` и удаляется при завершении запроса, в том числе при ошибке. Ответ находится в памяти запроса и в браузере пользователя. Это публичный сервис без учётных записей: не загружайте секреты и персональные данные. Встроенный пример доступен любому посетителю.

Прежние ограничения размера загрузки (25 MiB), распакованного объёма (100 MiB), количества элементов (300) и размера файла (16 MiB) сняты. Это не гарантия обработки произвольного объёма: доступны конечные ресурсы диска и контейнера. JSONL внутри RAR разбирается потоком, без загрузки всей трассы в RAM. Для JSON, CSV и обычных журналов по-прежнему используется разбор отдельного файла в памяти.

Чтобы не передавать миллионы строк в браузер, `records` содержит не более 500 первых записей, а каждая таблица — не более 500 первых строк; `fields` описывает записи этого предпросмотра. Полные количества передаются отдельно: `summary.record_count` и `tables._meta.counts`. Признаки `summary.records_are_preview` и `tables._meta.is_preview` явно отмечают неполную выдачу. Поиск и экспорт JSON/таблиц работают с возвращённым предпросмотром, а не со всеми исходными строками. `summary.run_count` считает логические запуски, `summary.attempt_count` — попытки. Ограничения сложности JSON, вложенности, длины строки JSONL (2 MiB), Python-literal метрики (1 MiB) и развёртки полей сохранены. Архивы с шифрованием, небезопасными путями, ссылками или подозрительной степенью сжатия отклоняются.

Ограничение HTTP body 26 MiB в приложении и 26 MB в Caddy снято. Допускается не более двух одновременных загрузок; при занятости слотов возвращается HTTP 503. Лимит RAM контейнера остаётся 768 MiB. Временный spool размещён на Docker volume, а не на 64 MiB tmpfs.

## Эксплуатация

```sh
docker compose ps
docker compose logs --tail 100 log-explorer
docker compose restart log-explorer
docker compose down
```

Контейнер запускается непривилегированным пользователем, с read-only файловой системой, без capabilities; заданы лимиты памяти, CPU, процессов и ротация технических журналов. Перезапуск после перезагрузки сервера обеспечивает Docker `restart: unless-stopped`. Обновление выполняется повторной сборкой; исходный код не монтируется в работающий контейнер.

Не следует передавать внешнему клиенту доступ к Docker, системным файлам или настройкам Caddy. Остановка этого приложения не требует остановки существующих Outline или Penpot.
