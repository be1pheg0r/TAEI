# Commit sheet — исследовательский журнал

1. **Signature:** один плотный, читаемый рабочий стол, где график и происхождение результата стоят рядом, а не рекламный hero.
2. **Цвет:** изумрудный OKLCH `oklch(0.55 0.12 160)`, restrained; нейтральный холодный бело-серый фон со светлотой около 0.97, графитный текст. Не кремовый, не фиолетовый и не синий «AI dashboard».
3. **Тип:** системный sans `Arial`/system-ui для текста плюс моноширинный для значений; без сетевого шрифта и без Inter.
4. **Слом сетки:** широкий основной сюжетный блок слева и узкая контекстная колонка справа; графики варьируют размер по назначению.
5. **Motion:** только короткие переходы состояний до 160 мс; никаких scroll-driven анимаций.
6. **Рефлекс:** общий dashboard — темная витрина KPI и однотипная сетка; избегаем этого через светлую бумажную поверхность, плотные таблицы и графики с реальными измерениями.
7. **Разрыв house tells:** нет near-black поверхности и моноширинных ярлыков по всему UI; нет логотипа/status/action как декоративного hero. Вместо них нейтральная навигация и точечная моноширина только у данных.
