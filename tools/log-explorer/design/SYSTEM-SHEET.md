# System sheet — исследовательский журнал

## Маршрутная карта
- Обзор: состояние эксперимента, происхождение данных, заметные счетчики; общая рабочая область.
- Графики: каталог независимых научно осмысленных представлений полей, с поиском и категориями.
- Записи: построчный журнал, фильтр/сортировка, раскрытие полного JSON.
- Все значения: нормализованные поля API, поиск, тип/источник/описание, сортировка и страницы.
- Файлы: состав архива и предупреждения, загрузка ZIP и выгрузка результата.

## Компоненты и варианты
- Кнопка: primary / secondary / quiet; состояния hover, focus, pressed, disabled, loading.
- Навигация: current / idle; current всегда обозначен текстом и маркером.
- Поле поиска: пустое / заполненное / сфокусированное.
- Карточка графика: обычная / широкая / недоступные данные; ECharts tooltip, zoom, data-view, CSV и PNG.
- Таблица: обычная / пустая / ошибка; сортировка и пагинация доступны с клавиатуры.
- Уведомление: info / warning / error.
- Панель загрузки: idle / dragging / loading / error.

Все экраны работают на одном клиентском наборе ответа API; состояния пустоты, загрузки и ошибки показывают восстановительное действие.
