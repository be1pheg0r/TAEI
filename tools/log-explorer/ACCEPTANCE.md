## Проверенный результат

- Production-сборка React/TypeScript/Vite выполнена внутри Docker.
- FastAPI обслуживает frontend и API через общий HTTPS-origin; Caddy выдаёт действующий сертификат.
- Контейнер `taei-log-explorer`: healthy, непривилегированный пользователь, read-only filesystem, автоматический restart.
- Предоставленный пользователем `logs-2.zip` действительно загружается через multipart API и браузер.
- В примере распознаны 11 логических записей, 101 поле, один запуск R15. Эксперимент `finished`, первичная приёмка `rejected`.
- В браузере подтверждены 43 уникальных идентификатора графиков и 43 представления с непустыми данными. Это визуализации конфигурации, QC-счётчиков, категорий, структуры архива и явно помеченных отношений. Некоторые содержат одну точку, потому что в примере один запуск. Это не 43 независимых измерения и не восстановленные временные ряды.
- Доступны поиск, сортировка, пагинация, раскрытие полной записи/поля, пояснения, экспорт JSON и CSV, а для графиков CSV/PNG и таблица данных.
- Проверены все пять вкладок при ширине 1440 и 390 px. Скриншоты созданы и визуально просмотрены; график счётчиков переведён в горизонтальный вид для читаемости на телефоне.
- Чужие архивы не сохраняются как общая сессия или общедоступный файл. Встроенный предоставленный пример публичен.

## Ограничения доказательств

Присланный ZIP содержит только run.log и пустой hydra.log. В нём нет самих строк трасс steps/requests/telemetry и измеренного throughput. Сервис не подменяет их синтетикой и не вычисляет длительность из количества снимков телеметрии. Дополнительные графики по реальным строкам появляются при загрузке соответствующих JSON/JSONL/CSV. Поддержка парсинга проверена отдельными явно синтетическими тестовыми строками, не GPU-исполнением.

Доступ публичный, без учётных записей; не загружайте секретные данные. Лимиты архива и инструкция эксплуатации — в README.md.

Дополнительная проверка перед коммитом: 129 тестов основного репозитория прошли. Ограничение размера запроса и двух одновременных загрузок применяется на ASGI-уровне до multipart-парсера, включая запросы без Content-Length. Регрессионные тесты проверяют HTTP 413 без выполнения endpoint, закрытие временных multipart-файлов и освобождение слотов после ошибок и отмены.
